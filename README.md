# Homework of the Course: Advanced Algebra

Personal homework archive for my **Advanced Algebra** course, typeset in LaTeX and maintained on GitHub. The repository is updated continuously as new assignments are released throughout the semester (or several semesters).

## Compiling

Only `main.tex` needs to be compiled. TeX Live is recommended.

## Notes

- This project is for personal use and course submission.

- Content is updated incrementally; earlier assignments may be revised.

- Compiled PDFs are generated locally and not tracked.
